# standard 티어 실측 — 팀 공유 스프레드시트 웹앱 (2026-10-01)

1부(`lab-2026-09-30.md`)에서 "한 세션이 혼자 끝낼 크기에서는 채팅으로 충분하다"가 나왔다. 이 문서는 그 반대 구간 — 한 세션을 넘는 크기 — 에서 standard · lite 티어가 채팅보다 나은지를 같은 방식으로 잰 기록이다.

## 1. 설계

- **주제** (모든 조건에 글자 하나 다르지 않게): `팀이 함께 쓸 스프레드시트 웹앱 — 파이썬 백엔드에 저장, 공유 링크로 같은 시트를 여러 사람이 열고 편집, 팀에 배포`
- **스킬 판정** (`--route-only`): creative · standard · product · greenfield. 백엔드 · 프런트 · 공유 링크 · 동시 편집으로 파일이 여러 개라 한 세션 크기를 넘고, "팀에 배포" 신호가 standard 를 고른다. 생성 세션 2회도 같은 판정이었다.
- **환경**: Linux, python3 3.12 · sqlite3 · websockets · uv · Docker 있음. node · 웹 프레임워크 없음 (세션들은 `uv` 로 FastAPI · aiohttp 를 설치했다).
- **세션**: 전부 헤드리스 `claude -p`, opus · `--effort medium` · `acceptEdits` · 같은 도구 허용 · 빈 디렉터리 (`~/work/bench-lab/run.sh`). 비용 상한 채팅 $8 · 생성 $4 · standard 실행 $25 · lite 실행 $10.
- **가설과 반증 조건은 실행 전에 적었다** (`~/work/bench-lab/hypotheses.md` 2부).

### 무엇이 갈랐나

- **UI 핵심 (63 대 59)**: 채팅 계열 넷이 틀린 것은 전부 `COPY-02~05` — 수식을 복사해 붙이면 상대 참조가 옮겨지지 않는다 (s01 은 수식이 아니라 값을 붙인다). 개선 요청 1회로도 안 고쳐졌다. 스킬 계열 셋은 처음부터 됐다 (`기본기:` 항목의 영향으로 보이나 분리해 재지는 않았다 — 어느 판정문도 이 항목을 지적한 적이 없다).
- **UI 확장**: 채팅 계열은 `1,234` · `50%` 를 텍스트로 받고(`INPUT-08 · 09`), s03 두 버전은 `$` 절대 참조를 지원하지 않는다. `COPY-09`(잘라내 옮긴 셀을 참조하던 수식이 따라감)는 7개 모두 틀렸다.
- **팀 기능**: 7개 전부 34/34. 실시간 전파 · 편집/보기 링크 · 프레즌스 · 재시작 유지는 모두 갖췄다. 변별은 배터리 밖 — 심사에서 났다.
- **심사가 공통으로 본 채팅 계열의 결함**: 같은 셀 동시 편집이 조용히 덮어써진다 · `10%` · `1,000` 이 `#VALUE!` · 390 폭에서 가로로 넘친다 (s01 제외) · 끊긴 동안의 입력이 사라진다 (s02).
- **standard 가 사는 것**: s04 는 같은 셀 충돌을 두 값으로 보여 주고 고르게 하고, s05 는 덮어쓴 사실을 알리고 기록에서 되살리게 한다. 둘 다 끊긴 동안의 입력을 보관하고, 2–3라운드에 걸쳐 검증자가 찾은 기본기 결함(행·열 삭제 되돌리기, Tab 뒤 Enter, 제목 Enter 로 셀 삭제, 390 폭 아바타 잘림 등)을 고쳤다. 남은 결함도 스스로 밝혔다 (s04 정렬이 합계 행을 섞음, s05 표시 결함 1건).
- **lite 가 못 미친 것**: README 가 주장한 충돌 표시가 0.3초 차 동시 편집에서는 뜨지 않았고 (심사 1), 보기 전용 링크가 없고, 390 폭이 깨졌다 (심사 2).

## 4. 결론

1. **한 세션을 넘는 크기에서는 스킬이 값을 한다.** lite 도 채팅을 앞서고(핵심 63 대 59, 심사 +2~+9), standard 는 더 앞선다(심사 +6~+13). 채팅은 백엔드 · 동기화에 힘을 쓰면서 스프레드시트 기본기를 놓쳤고, 개선 요청 한 번으로도 돌아오지 않았다.
2. **값은 비싸다.** lite 는 채팅의 약 3배, standard 는 약 9배다. 시간은 26분 / 65–83분.
3. **1부와 합치면**: 한 세션이 혼자 끝낼 크기 → 채팅 (skip), 한 세션을 넘는 크기 → lite 또는 standard. 지금 라우팅이 그렇게 되어 있다.
4. **스킬에 반영**: 검증자 · 심사자는 포그라운드로 호출한다 — `-p` 에서는 턴이 끝나면 백그라운드 결과를 받지 못한다 (template · contract · 검사기 · 음성 케이스).
