## A. 기준선 초과 — 통과
- 근거: `verify/week-1440.png`, `verify/week-1440x900.png` 육안 판독, 코드 311–320줄(`clashes()`, 조건 `a.start<b.end&&b.start<a.end`, 모든 쌍을 셈). 배지 마크업은 377줄.
- 날짜 헤더 배지와 화면에서 센 겹침 쌍:
  - 9/28(월) 배지 1 ↔ 아키텍처 리뷰 10:00–11:30 × 고객사 콜 11:00–12:00 = 1쌍. 일치.
  - 9/29(화) 배지 없음 ↔ 스탠드업·디자인 크리틱·점심 멘토링·스프린트 계획은 서로 겹치지 않음 = 0쌍. 일치.
  - 9/30(수) 배지 2 ↔ 채용 인터뷰 × 제품 리뷰, 1:1 김팀장 × 보안 점검 = 2쌍. 일치.
  - 10/1(목) 배지 없음 = 0쌍. 일치.
  - 10/2(금) 배지 1 ↔ 전사 타운홀 × 벤더 데모(10:00–11:00 동일) = 1쌍. 일치.
- 겹친 일정 표시: 빨간 테두리, 사선 해칭, "!" 아이콘(116–120줄). 사이드바 "겹치는 일정 4쌍" 목록도 합계 1+0+2+0+1=4와 일치.
- 겹침 쌍이 있는 날 3일이 모두 배지와 일치(요구 기준은 2쌍 이상).

## D. 대비 — 통과
CSS 변수 10–19줄의 hex 값을 python으로 계산(sRGB 상대 휘도, (L1+.05)/(L2+.05)).
- 일정 칩 글자/배경(4개 분류). 가장 낮은 값은 외부 미팅 `#592804`/`#fde6cf`로 제목 **10.06**.
  - 겹침 해칭 `rgba(180,35,24,.10)`을 합성한 배경: 7.61–9.49.
  - 메타 줄 opacity .95를 반영한 값: 최저 7.61.
  - 분류별 제목 대비: 집중 11.04, 회의 10.65, 외부 10.06, 개인 11.09.
- 시간 라벨 `--ink-2 #4f4a3f` / 격자 `--surface #fffdf8`: **8.67**. 보조 시간대 라벨 `--ink-3 #6b6557`: 5.70.
- 겹침 배지 `#ffffff` / `--clash #b42318`: **6.57**.

## E. 390 폭 — 통과
- 지정 명령(`--window-size=390,931 --dump-dom`)의 결과는 `{"sw":500,"iw":500}`.
  - headless 창의 최소 폭이 500으로 고정돼, 이 명령으로는 390을 재현하지 못함. 오버레이 주입 캡처(`verify/probe-width-390.png`)에서도 iw=500으로 표시됨.
  - 폭 500 기준으로도 sw ≤ iw.
- 대체 증거로 390×931 iframe 래퍼를 사용(`verify/frame390.html` + `verify/probe-width-inner.html`, postMessage로 값 전달).
  - 결과는 `{"sw":390,"iw":390,"bsw":390}` (exit 0). sw ≤ iw 충족.
- `verify/frame390.png`(실제 390 레이아웃)와 `verify/narrow-390.png`: 사이드바가 숨겨지고 **일 보기**(9/30 한 열)로 전환됨. 툴바에 일/3일 토글과 "겹침 2" 칩, 헤더에 배지 2가 있음. 제목(스탠드업, 채용 인터뷰, 제품 리뷰, 1:1 김팀장, 보안 점검, 문서 정리)이 모두 판독 가능하고 가로 넘침이 없음. 전환 로직은 336–341줄(≤560 일, ≤900 3일).

## 정확성 결함
- 이번 판정 범위에서 확인된 정확성 결함은 없음. 겹침 판정은 끝-시작 경계를 겹침으로 세지 않음(엄격 부등호). 배지 수치와 화면이 일치함.

## 수용된 제약
- headless Chrome의 창 최소 폭(500px) 때문에 지정된 390 dump-dom 명령은 innerWidth=500을 반환함. 390 판정은 iframe 래퍼로 얻은 실측값으로 대체함. 산출물의 결함이 아니라 도구의 제약임.
- 1440 캡처는 지정대로 987 높이로 찍음. 체크리스트의 900 뷰포트 조건은 별도의 1440×900 캡처로 확인함.
- 대비는 지침에 따라 CSS hex 값으로 계산함. 해칭과 opacity는 알파 합성 근사로 반영함(안티앨리어싱 픽셀은 측정하지 않음).

## 남은 간극이 요구사항 때문에 불가피한지
체크리스트 A–E는 모두 실측 증거로 충족돼, 판정에 영향을 주는 간극은 없다. 남은 것은 두 가지다. 하나는 "아키텍처 리뷰"처럼 좁은 겹침 열에서 제목이 두 줄로 줄바꿈되는 점이고, 다른 하나는 메타 줄의 장소가 말줄임되는 점이다. 둘 다 1440 폭에서 주 5열에 겹침 일정을 나란히 분할해 보여 달라는 요구가 만든 폭 제약에서 나온다. 제목 한 줄 판독이라는 요구는 지켜지므로 요구사항이 강제한 수용 가능한 결과로 본다.
