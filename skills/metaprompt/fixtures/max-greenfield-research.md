# 목표

BM25 상위 100건을 교차 인코더로 재랭킹했을 때 nDCG@10 이 유의미하게 오르는지 입증하는 실험 코드와 리포트를 만들어줘.
**BEIR 서브셋 3개(SciFact·NFCorpus·FiQA) 의 BM25 기준선** 대비여야 한다.
Python 3.11, GPU 1장 이하, 공개 데이터셋만. 결과는 `report.md` 와 재현 커맨드 하나로 남긴다.

"개선된 것 같다"가 아니라 "3시드 이상에서 95% 신뢰구간이 겹치지 않는 수준"이 목표다.
기준선을 약하게 두고 이긴 결과, 시드 하나로 낸 결과는 실패다.

## 기준점 상세

- 재현 대상: 공개 BM25 기준선 nDCG@10 — SciFact 0.665 / NFCorpus 0.325 / FiQA 0.236 (BEIR 공식 설정, k1=0.9 b=0.4) (예시 수치)
- 지표 정의: pytrec_eval 의 ndcg_cut_10, 표준 qrels, 테스트 분할만 평가
- 표준 비교 대상: 동일 조건의 MiniLM 계열 교차 인코더 재랭킹 보고값 (예시: SciFact 0.68대)
- 알려진 함정: 학습 데이터(MS MARCO)와 평가셋의 문서 중복, 재랭킹 후보 수(100 vs 1000)에 따른 비교 불공정
- 계산 예산: 데이터셋당 재랭킹 30분 이내(T4 기준), 총 3시드 × 3셋
