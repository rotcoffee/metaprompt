# precise — 정답이 정해진 작업 (버그 · 마이그레이션 · 리팩터링 · 수치 목표 · 재현)

올바른 로직과 회귀가 전부다. 외부 기준점도, 블라인드 비교도, 리서치 서브에이전트도 없다 — 토큰을 테스트에 쓴다.

## 1. 기준점 — base commit 과 명세

- worktree: base commit 이 바닥이자 비교 대상이다. 사실 3개 이상을 환경 JSON · 저장소 · 스카우트(standard+)에서 — 현재 테스트 통과 상태, 증상 재현 절차, 관련 모듈·호출부 수.
- greenfield: 명세(RFC·스키마·요구 조항)가 기준점이다. 조항 번호를 사실로 넣는다.
- 외부 리서치를 하지 않고, 프롬프트에도 리서치 팬아웃·리서처 역할을 넣지 않는다. 필요한 외부 사실(API 변경점 등)은 기준점 상세에 `(출처 미확인)` 과 함께 한 줄로.

## 2. 빨강 먼저, 그리고 잠금

프롬프트의 순차 항목 맨 앞에 이 순서를 넣는다.

1. 증상·명세 조항을 검사하는 **실패하는 회귀 테스트**를 쓴다. 고치기 전에 테스트 커맨드가 exit ≠ 0 임을 확인하고 `round 0: red` 로 커밋한다.
2. 이후 그 테스트 파일은 수정 금지 — `git diff <red SHA>..HEAD -- <테스트 경로>` 가 비어야 한다. 테스트가 틀렸다고 판단되면 멈추고 보고한다.
3. 수정 → 테스트 exit 0 → 전체 회귀 스위트 exit 0.

만든 쪽이 채점하지 않는 장치가 이것이다: 테스트는 수정보다 먼저 고정되고, 종료는 종료 코드가 판정하고, `/goal` 의 평가자(새 컨텍스트)가 턴마다 그 출력을 읽는다. `mp-verifier` 는 마지막 라운드에 한 번만, 정확성만 본다 — 테스트가 명세를 실제로 검사하는가, diff 가 증상만 가리는가.

수치 목표도 같은 모양이다: system 은 목표를 assert 하는 벤치 스크립트(반복 중 최댓값 기준), research 재현은 보고치 ± 허용오차를 assert 하는 스크립트. 둘 다 종료 코드로 끝난다.

## 3. 체크리스트 원형 — 전부 커맨드로 판정

- 회귀 테스트가 red 커밋에서 exit ≠ 0, HEAD 에서 exit 0 인가 (필수)
- red 이후 테스트 파일 diff 가 0줄인가 (필수)
- 전체 스위트가 exit 0 이고 base 에서 통과하던 것이 전부 통과하는가
- 수정이 원인 지점에 있는가 — 증상 우회(예외 삼키기·재시도 추가·타임아웃 증가)면 No
- 도메인 레퍼런스 2절의 불변식 (system: 등가성·꼬리 지표 / research: 누수 0건·시드 고정)

## 4. 종료와 `/goal`

종료 조건: `<테스트 커맨드>` 와 `<회귀 커맨드>` 의 종료 코드가 모두 0 · 잠금 diff 비어 있음 · 체크리스트 전 항목 Yes · 최대 M 라운드.
프롬프트에 `/goal` 줄을 그대로 넣는다 (조건은 4,000자 이내, 평가자는 대화에 드러난 출력만 본다):

    /goal <프롬프트 경로> 를 읽고 따른다. 완료: `<테스트 커맨드>` 와 `<회귀 커맨드>` 가 exit 0 으로 출력되고 `git diff <red SHA>..HEAD -- <테스트 경로>` 가 비어 있음. 또는 <M> 라운드 후 멈추고 보고

## 5. 스위치 — contract 조건을 이 경로에 적용한 기본값

| 스위치 | 기본 | 예외 |
|---|---|---|
| agent teams | OFF — 순차·같은 파일·의존이 많은 작업 | standard+ 대화형 · 원인 불명 · 경쟁 가설 ≥3 이 서로 다른 모듈에 있을 때 **진단 단계에만 ON** (가설마다 팀원이 반박). 수정은 한 명 |
| Workflow | OFF | 독립 검증 매트릭스(플랫폼·버전 ≥5) 증거 수집에만, 대화형 `ultracode` |
| 루프 | `/goal` ON — 완료가 종료 코드라 새 컨텍스트 평가자가 판정할 수 있고 `-p` 에서도 돈다 | 검증 실행 한 번이 ≥15분(학습·지속 부하)이면 **`/loop` 가 우선** — `/goal` 의 유휴 체크인은 3회에서 멈춘다. 이때 `/goal` 줄 대신 `/loop` 로 붙여 넣고 종료 조건은 본문에 둔다 |
