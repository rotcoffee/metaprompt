# creative — 새로 설계하고 비교로 품질이 갈리는 작업

따라잡기만 하는 체크리스트는 기준점의 복제품을 만든다. 이 경로는 **기준점이 하지 않는 것 하나**를 체크리스트로 강제한다.

## 1. 기준점 — 실명 제품·방법 + 수치 사실

"업계 최고"·"요즘 앱처럼"은 기준점이 아니다. 이름이어야 검증자가 그 공개 자료를 결과물 옆에 놓는다. 도메인 레퍼런스 1절이 수집 항목을 정한다.

- lite: 에이전트 없음. 체크포인트에서 고른 후보를 검색 최대 1회로 보강, 확인 못 한 사실은 `(출처 미확인)`.
- standard+: `metaprompt:researcher` × contract 의 R, 한 메시지에서 동시에. max 는 후보 조사 · 실패의 정의와 비교 리뷰 · 도메인 함정으로 나눈다. 프롬프트에 넣을 것: 주제 · 도메인 레퍼런스 1절 그대로 · `--benchmark` 가 있으면 후보 1로 고정 · 아래 반환 형식.

```
반환은 40줄 이내, 이 형식만. 검색 본문·인용문을 붙이지 마라.
후보 1: <기준점> — 사실 (1) … (2) … (3) … [수치 우선] — 출처: <URL>
후보 2: … / 후보 3: …
기준점이 하지 않는 것: <후보별 알려진 한계·리뷰 불만·트레이드오프로 포기한 것 2개> — 출처
실패의 정의: "<리뷰 표현 그대로, 없으면 '없음'>" — 출처
```

## 2. 앞서기 항목 — 필수 1개 이상

체크리스트에 아래 꼴의 항목을 **정확히 이 머리말로** 넣는다. `check_prompt.py` 가 머리말과 기준점 이름을 찾는다.

    - [ ] 앞서기: <기준점>에는 없는 <기능·속성>이 있고, <증거 방법>으로 확인되는가

- 후보는 1절의 "기준점이 하지 않는 것"에서 고른다. 리뷰 불만을 해소하는 것이 가장 좋고, 기준점이 일부러 포기한 것(미니멀리즘이 버린 밀도)은 상충 위험이 크다 — 3단계 동시 만족 점검에서 본다.
- 증거 방법은 도메인의 것 (렌더 캡처 · 재현 수치 · 계측). "더 직관적" 같은 의견은 증거가 아니다.
- 나머지 항목은 도메인 레퍼런스 2절 원형에서. 앞서기·기본기 항목도 contract 의 C 안에 센다.

**기본기 항목 1개도 필수** (머리말 `기본기:`). 빌더는 프롬프트를 닫힌 명세로 읽는다 — 실측 2건에서 저장·숫자 입력 해석·원소별 확정 표시가 빠졌고 검증자는 5/5 를 줬다.

- 동작 3~5개를 기준점이 아니라 **주제**에서 뽑는다 (안 되면 "고장"이라 할 것). 목록은 하한이다.
- "범위 밖" 문장과 제품 안의 검증용 훅(`window.X`·고정 선택자)을 프롬프트에 쓰지 않는다 — 적힌 제외는 상한이 되고 빌더는 제품 의미를 프로브에 맞춘다 (실측).

실패의 정의는 리뷰 표현이 있으면 그대로, 없으면 이 주제의 "평범함"을 실명으로 한 문장 — "<기본 위젯·템플릿>과 구분되지 않으면 실패".

## 3. 검증과 종료

- 검증자 `mp-verifier` 를 매 라운드 새 컨텍스트로 띄운다. 판정은 커맨드로 얻은 증거(렌더·재현·계측)만.
- standard+: `mp-judge` 가 결과물과 기준점 자료를 이름을 가리고 5축 100점으로 채점한다. 종료 점수는 도메인 레퍼런스 4절. 심사자가 정체를 알아봤으면 판정문에 적는다.
- 종료: 체크리스트 전 항목 Yes (+ standard+ 점수) · 최대 M 라운드.

## 4. 스위치 — contract 조건을 이 경로에 적용한 기본값

| 스위치 | lite | standard+ |
|---|---|---|
| agent teams | OFF — 빌더 하나, 조율할 흐름이 없다 | 대화형이고 콘셉트가 갈릴 때만 **발산 단계에만 ON**: 팀원 3명이 서로 다른 콘셉트 시안 → 서로 반박 → 하나 선택. 빌드는 단일 빌더. 한 파일 산출물이면 OFF |
| Workflow | OFF | max 대화형에서 증거 실행(캡처 세트·블라인드·콜드 리더) ≥5 일 때 증거 수집에만 ON |
| 루프 | 내부 라운드 — 판정이 검증자 판단이라 `/goal` 의 Haiku 평가자가 대신할 수 없다 | 같음. 검증 실행 한 번이 ≥15분이면 `/loop` |
