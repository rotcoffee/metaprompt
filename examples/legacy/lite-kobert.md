# 목표

소규모 한국어 텍스트 분류에서 KoBERT 미세조정이 TF-IDF + 로지스틱 회귀보다 정말 나은지 입증하는 실험 코드와 `report.md` 를 만들어줘.
**NSMC(네이버 영화 리뷰 감성 분류)를 학습 500 / 2,000 / 10,000 건으로 서브샘플한 조건에서, 공정하게 튜닝된 TF-IDF+LR 기준선** 대비여야 한다.
Python 3.11 · GPU 없으면 CPU 로 (KoBERT 는 n=10,000 에서 3 epoch 이내) · 공개 데이터셋만 · 결과는 `report.md` 와 재현 커맨드 하나(`python run.py --all`).

"동작하는 수준"이 아니라 "같은 분할·같은 검증셋·같은 탐색 예산으로 비교해도 밀리지 않는 수준"이 목표다.
기준선을 기본 하이퍼파라미터로 두고 KoBERT 만 튜닝해서 이긴 결과, 테스트셋으로 조기 종료나 튜닝을 한 결과는 실패다.

## 기준점 상세

- NSMC 는 학습 150,000 / 테스트 50,000 건의 이진 감성 데이터이고 평가는 테스트셋 정확도다 — 출처: https://github.com/SKTBrain/KoBERT (README)
- 전체 데이터 미세조정 보고값: KoBERT 0.901 · BERT-base-multilingual-cased 0.875 · KoGPT2 0.899 — 출처: 위 README. 소규모 조건의 보고값은 없으므로 이 실험이 직접 만든다
- transformers 기반 참고 구현: https://github.com/monologg/KoBERT-nsmc — 토크나이저·학습 루프를 처음부터 짜지 않는다
- TF-IDF 문자 2~4gram + 로지스틱 회귀는 전체 데이터에서 정확도 약 0.82~0.85 (출처 미확인)
- 학습 2,000 건 이하에서는 사전학습 모델의 우위가 크고, 10,000 건 이상에서 격차가 줄어드는 경향 (출처 미확인) — 그래서 규모 3개를 본다
- 함정: 테스트셋으로 하이퍼파라미터·에폭 선택(누수), 기준선만 기본값(불공정 비교), 시드 1개로 결론 (출처 미확인)

## 실행 예산 (tier: lite)

- 라운드 상한 **2**. 팬아웃 없음 — 빌더 하나, 검증자 하나.
- 서브에이전트 보고는 **30줄 이내**로 받아라. 코드·로그 전체를 부모 컨텍스트로 올리지 마라. 상세는 파일에 두고 경로와 결론만 보고한다.
- 검증자 판정문은 `verdicts/round-N.md` 에 저장한다. 다음 라운드 작업 지시는 **실패 항목만** 추려서 넘긴다.
- 라운드마다 커밋한다 (`round N: <한 줄 요약>`). 커밋이 없으면 중간 상태 복원도, 개선 전후 비교도 못 한다.
- 검증 증거 범위: 재현 1회(결정성 확인 생략) · 누수 점검 · 반증 1개(다른 시드)

## 순차로 진행할 것 (쪼개지 마)

아래 전부를 빌더 하나가 순서대로 처리한다. 병렬화하지 마라 — 이 티어는 이음매를 다시 붙일 예산이 없다.
서브샘플 고정(시드 → 인덱스 파일) → 학습/검증 분할 → TF-IDF+LR 기준선(검증셋으로 C·n-gram 탐색) → KoBERT 미세조정(같은 검증셋으로 lr·epoch 탐색, **같은 시도 횟수**) → 테스트 평가 → 표와 `report.md` 는 한 에이전트가 처음부터 끝까지 맡아.
이유: 전부 같은 분할과 같은 지표 정의에 쓰기를 한다. 쪼개면 각 조각은 맞는데 분할이 어긋나 결과가 무의미해진다.
여기를 병렬로 쪼개면 부분별로는 그럴싸해 보여도 이음매에서 버그가 난다.

## 검증

만드는 에이전트와 **별개의** 검증 에이전트를 둬. 자기가 만든 걸 자기가 채점하지 마.
검증자는 아주 가혹한 비평가여야 하고, 기본 태도는 거부다.

**검증자는 다음 방법으로 직접 증거를 확보한 뒤 판정해라. 추정하지 마라.**

```
검증자는 보고된 숫자를 믿지 마라. 직접 실행해서 재현한 값만 근거로 인정한다.

1. 재현: `python run.py --size 2000 --seed 0` 을 그대로 돌려 두 방법의 테스트 정확도를 재산출하고 report.md 의 값과 차이를 적어라. 재현이 안 되면 그 자체가 실패다.
2. 누수 점검: 학습·검증·테스트 문서를 해시로 대조해 중복 0건임을 보여라. 서브샘플 인덱스 파일이 시드에서 재생성되는지도 확인해라.
3. 기준선 공정성: 탐색 로그에서 기준선과 KoBERT 의 시도 횟수와 검증셋이 같은지 확인해라. 약한 기준선을 이긴 것은 이긴 것이 아니다.
4. 반증 시도 1개: 다른 시드(--seed 1)로 n=2,000 을 다시 돌려 결론 방향이 뒤집히는지 봐라. 뒤집히면 보고해라.
5. 학습 시간(초)과 사용 장치를 함께 보고해라. 비용을 숨긴 개선은 개선이 아니다.

환경 제약으로 실행할 수 없으면 그 사실과 범위를 판정문에 명시하고 정적 검토만 했음을 밝혀라. 조용히 넘어가지 마라.
```

체크리스트 — 전 항목 Yes여야 통과:

- [ ] 학습·검증·테스트 분할 간 중복 문서가 해시 대조로 0건이고, 서브샘플 인덱스가 시드 파일로 저장돼 재생성되는가
- [ ] 기준선(TF-IDF+LR)과 KoBERT 가 같은 검증셋과 같은 탐색 예산(시도 횟수 동일)으로 튜닝됐고 그 로그가 남아 있는가
- [ ] 시드를 고정하고 동일 커맨드로 두 번 돌려 기준선 정확도가 소수 셋째 자리까지 일치하고 KoBERT 는 ±0.005 이내인가
- [ ] 학습 규모 500 / 2,000 / 10,000 각각에 대해 두 방법의 테스트 정확도·F1·학습 시간이 한 표에 기록됐는가
- [ ] 재현 커맨드 하나(`python run.py --all`)로 그 표 전체가 다시 생성되는가

검증자는 아래 형식으로 `verdicts/round-N.md` 에 남겨라.

- 항목별 **pass/fail 과 근거**(재현된 수치·스크립트 경로·로그 라인). 근거 없는 pass 는 무효다.
- **수용된 제약**: 이 과제의 전제상 원리적으로 해결 불가능한 지적은 실패가 아니라 여기에 적어라. 실패로 집계하면 정체 감지 규칙이 잘못 발동한다.
- 남은 격차가 **요구사항 자체에서 강제된 것인지** 한 문단으로 답해라. 개선이 없으면 없다고 판정해라.
- 점수는 보조 신호다. 항목별 판정과 근거 수치가 1차 결론이다.

## 종료 조건

아래 중 하나에 도달하면 종료 · 최대 2라운드.

(A) 입증: 체크리스트 전 항목 Yes + 3개 규모 중 2개 이상에서 KoBERT 테스트 정확도가 기준선보다 0.02 이상 높음 (단일 시드이므로 report.md 에 "예비 결과"로 표기)
(B) 기각: 체크리스트 전 항목 Yes + 위 조건 미달이 재현 가능하게 확인됨 → 정당한 종료다. 어떤 규모에서 격차가 없었는지, 어떤 조건(다중 시드·다른 규모)에서 다시 볼 만한지 보고해라. 숫자를 만들려고 라운드를 더 태우지 마라.

미달이면 지적된 항목만 다시 만들어서 재검증해. 2라운드까지 통과 못 하면 멈추고 남은 미달 항목과 그 이유를 보고해.

검증자의 **판정**은 받아들이되 **처방**은 체크리스트 전체와 대조해라. 한 항목을 고치려다 다른 항목을 깨는 제안이 나올 수 있다. 통과 조건은 전 항목 Yes이므로 그런 교환은 손해다.

같은 지적이 2라운드 연속 반복되면 접근 방식이 틀린 것이다. 멈추고 보고해. (수용된 제약으로 분류된 항목은 이 카운트에서 제외한다.)
